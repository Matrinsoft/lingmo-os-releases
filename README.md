# Lingmo OS Releases

Aggregated `.deb` packages from all Lingmo OS component repositories.

## Usage

Go to [Actions](../../actions/workflows/aggregate.yml) and click **Run workflow** to build a new release with the latest `.deb` packages from all components.

The release tag will be `build+YYMMDD+HHmm` (UTC) unless you specify a custom tag.
